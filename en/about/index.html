About

Hack4Impact Polytechnique Montréal

Hack4Impact Polytechnique Montréal is a group of Polytechnique Montréal students who build web and mobile apps for nonprofit organizations.

Mission

The chapter's mission

Hack4Impact exists for both nonprofits and students. The chapter connects the two so useful tools get built.

  • Build tools with nonprofits, based on their real needs.
  • Give students hands-on experience on a project that is actually used.
  • Share lessons learned with the other chapters in the network.
  • Make Hack4Impact known to students and nonprofits in Montréal.

Principles

Work methodology

Code comprehension

Every project starts with a product requirements document (PRD) written with the organization. The PRD sets what is essential and what can wait.

Code reviews

Every change goes through a code review. It keeps the project solid and everyone learns by reading each other's work.

Tool handoff

At the end, the tool belongs to the organization, which receives the code and the documentation to keep using it.
