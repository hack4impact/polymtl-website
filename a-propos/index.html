À propos

Hack4Impact Polytechnique Montréal

Hack4Impact Polytechnique Montréal est un groupe d'étudiants de Polytechnique Montréal qui développe des applications web et mobiles pour des organismes à but non lucratif.

Mission

Mission du chapitre

Hack4Impact existe pour les organismes et pour les étudiants. Le chapitre relie les deux pour que des outils utiles voient le jour.

  • Développer des outils avec les organismes, à partir de leurs besoins réels.
  • Donner aux étudiants une expérience concrète sur un projet utilisé pour vrai.
  • Partager les apprentissages avec les autres chapitres du réseau.
  • Faire connaître Hack4Impact aux étudiants et aux organismes de Montréal.

Principes

Méthodologie de travail

Compréhension de code

Chaque projet commence par un product requirement document (PRD) rédigé avec l'organisme. Le PRD fixe ce qui est essentiel et ce qui peut attendre.

Revues de code

Chaque changement passe par une revue de code. Ça garde le projet solide et tout le monde apprend en lisant le travail des autres.

Remise de l'outil

À la fin, l'outil appartient à l'organisme, qui reçoit le code et la documentation pour continuer à l'utiliser.
